# 결과 예시: 고객 수정 요청을 모으는 웹앱

프리랜서가 고객 수정 요청을 받는 웹앱을 만들어 한국에서 월 9,900원에 팔려고 한다면 무엇부터 확인해야 할까요?

아래는 그 질문으로 실제 생성한 내부 시험 결과입니다. **BriefLoop는 가상 제품이며 고객 성과가 아닙니다. 생성 버전은 2026-09-28 method-parity 시험본으로, 최신 R2보다 이전 버전입니다.**

## 먼저 볼 부분

보고서의 4장은 국내외 경쟁 제품뿐 아니라 무료 폼과 기존 메신저도 대안으로 비교합니다. 5장은 각 서비스의 과금 단위를 나눠 보고, 경쟁사 가격이 내 제품의 결제 수요를 증명하지는 않는다고 구분합니다. 나머지 절에서는 첫 고객군, 홍보와 확인할 행동을 정리합니다.

예시를 보기 좋게 만들려고 긍정적인 결론으로 바꾸거나 성공 점수를 덧붙이지 않았습니다. 원래 보고서가 항상 정확하다는 뜻은 아니며 별도 독립 출처 검토와 비교 판정은 끝나지 않았습니다.

상단 안내와 이 파일은 공개용으로 추가했고, `REPORT.md`와 `SOURCES.md`의 본문은 기존 출력 그대로입니다. `INPUT.md`에는 실행 관리용 문장 대신 실제 제품 설명과 사용자 요청 부분을 담았습니다.
