# 시험에 사용한 질문

아래는 내부 가상 사례입니다. 실제 서비스나 고객 성과가 아닙니다.

프리랜서가 고객의 수정 요청을 한곳에 모아 확인하는 웹 서비스 BriefLoop를 바이브코딩으로 만들었다고 가정해 주세요. 고객별 공유 링크로 수정 요청을 받고, 프리랜서는 상태와 메모를 관리하는 MVP입니다. 외부 메신저 연동과 결제 기능은 아직 계획 단계이고 고객 사용 데이터는 없습니다. 한국에서 일하는 1인 프리랜서가 대상이며 월 9,900원을 받을 수 있을지 고민 중입니다. 혼자 운영하고 광고비나 유료 조사 도구는 쓰지 않을 생각입니다.

현재 확인 가능한 공개 자료를 조사해서 시장, 기존 대안, 고객이 바꿀 만한 이유, 가격과 무료 홍보 방법, 먼저 고치거나 확인할 것을 한국어 시장조사 보고서 파일로 주세요. 사실과 가정, 확인하지 못한 것은 구분하고 출처도 남겨 주세요. 제 제품이 가상이라는 표기를 유지해 주세요.

새 계정, 결제, 외부 게시나 실제 사용자 접촉은 하지 마세요. 접근할 수 없는 자료를 읽었다고 하지 말고 가능한 범위에서 보고서를 완성해 주세요. 판매 카피 작성 요청은 아닙니다.
