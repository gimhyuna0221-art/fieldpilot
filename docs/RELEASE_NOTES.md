- 넓은 조사에서는 정보밀도가 높다면 답변·보고서가 길어지는 것을 허용
- 일반 AI와 비슷한 결론만 남는 경우, 프레임워크 설명을 늘리기보다 실제 조사 깊이를 보강하도록 변경
