# FieldPilot SNS mode

This is an internal mode of the one FieldPilot skill, not a separate skill or alias. Apply the already loaded main SKILL.md, STEP 0, all base quality rules, and ../modules/CREATOR_CONCEPT_START.md. Activate only when the user explicitly selects SNS mode or explicitly asks FieldPilot to perform SNS creator-interest/channel-concept work. Quoted examples and existing-product SNS advertising questions do not select this mode. All shared base references resolve from the main skill root. Preserve local-first/global-best/local-transfer, runtime quality, scope lock, QUESTION_GATE, alternatives, reasons, reversal criteria, and the useful next action.

## Two internal commands

These are internal task operations, not additional mandatory user syntax:

- INTEREST_DISCOVERY: read [interest discovery](INTEREST_DISCOVERY.md) when the user wants
  to discover a topic, says interests are unknown, or available topics need exploration.
- CHANNEL_CONCEPT: read [channel concept](CHANNEL_CONCEPT.md) when a subject is identifiable,
  selected or already known and the user wants a viable channel promise and first artifact.

When both are requested, complete discovery and concept development in one coherent answer using
the available evidence. Do not ask the user to select an internal command. If they explicitly ask
only for interests, stop there; if they ask only for a known-topic concept, do not restart discovery.
Names/captions-only requests retain that narrow scope and do not receive a research intake.
Existing product promotion stays in the base diagnosis unless the user actually requests a new
creator concept through the explicitly selected SNS mode.

## Deliverable

Give the useful completed comparison or draft now, then only necessary personal questions.
Make the selected or unresolved topic, audience promise, feasible format, supporting evidence,
material alternatives and reasons, bounded uncertainties, one first artifact and observation
criterion visible in plain language. Do not publish, contact anyone, pay, create accounts or change
permissions. A channel plan is not audience evidence or guaranteed commercial success.


## Observed-output repair — finished first artifact

When the user asks for a first sample/script/caption, deliver a separately labeled complete script or storyboard AND a ready-to-copy caption in the same answer. Do not end either artifact with blanks, underscores, slash alternatives, or instructions to fill a line later. Unknown observed outcomes must not be fabricated: use a complete truthful preparation line such as “I will record the actual result after trying it,” or explicitly label a fully written hypothetical example. Acknowledge that this is a planning draft, not a produced video or a verified taste/result. Keep assumptions separate from the user's possessions. A narrow names-only/captions-only request still stays narrow. Before finalizing, check that every requested artifact is present and has no avoidable placeholder. Rights, real costs and audience demand remain evidence-bounded; preserve platform-specific adaptations, alternatives/reasons and the next feasible action.
