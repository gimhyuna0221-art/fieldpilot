# FieldPilot

바이브코더를 위한 시장조사 스킬입니다. Claude Code나 Codex 안에서 경쟁 제품과 공개 자료를 조사하고, 지금 판단할 수 있는 것과 더 확인해야 할 것을 정리합니다.

[한국어 소개와 결과 예시](https://github.com/gimhyuna0221-art/fieldpilot) | [설치 안내](https://github.com/gimhyuna0221-art/fieldpilot/blob/main/docs/INSTALL.md)

## 시작하기

전체 `fieldpilot` 폴더를 호스트의 스킬 디렉터리에 설치하세요. `SKILL.md`만 복사하면 필요한 참고 자료와 도구가 빠집니다.

- Claude Code: 프로젝트의 `.claude/skills/fieldpilot/`에 넣고 `/fieldpilot`으로 호출
- Codex: 프로젝트의 `.agents/skills/fieldpilot/`에 넣고 `$fieldpilot`으로 호출

```text
/fieldpilot
프리랜서가 고객 수정 요청을 모아 보는 웹앱을 만들었어.
한국에서 팔고 싶은데, 비슷한 서비스와 무료 대안부터 찾아줘.
지금 뭘 바꾸거나 확인해야 할지도 봐줘.
```

질문을 잘 쓰는 것보다 제품과 현재 고민을 알려주는 것이 먼저입니다. 찾을 수 있는 내용은 AI가 먼저 조사하고, 판단에 필요한 정보가 없으면 그 부분만 묻게 구성했습니다. 모든 모델과 질문에서 같은 깊이의 결과가 나온다는 검증은 아직 충분하지 않습니다.

## 포함된 것

- `SKILL.md`: 질문과 상황에 맞는 조사 경로 선택
- `references/`: 조사 방법, 근거 확인, 보고서 작성과 판단 기준
- `tools/`: 출처 기록, 보고서 변환, 제한된 CSV 이벤트 분석과 검사 도구
- `tests/`: 계산 및 계약 검사와 시험 입력

경쟁업계의 방법을 참고했지만 모든 서비스와 연결되거나 같은 성능을 내는 제품은 아닙니다. 전문 서비스로 넘길 분석과 아직 확인하지 못한 자료도 구분합니다. 개발 목록 전체를 일반 조사 때마다 읽을 필요는 없습니다.

현재 품질 우선 프로필은 사용량 절감보다 경쟁사·대체재·인접 레퍼런스 발견력과 비교 깊이를 우선합니다. 중복 검색과 반복 읽기는 줄이되, 결과를 차별화하는 유용한 발견과 세부 비교는 단순히 짧게 만들기 위해 제거하지 않습니다.

별도 국가를 적지 않아도 `market-anchor-01`이 먼저 작동합니다. 한국어처럼 특정 상업 생태계와 강하게 연결된 언어는 그 시장을 잠정 1차 검색시장으로 두고, 영어·스페인어처럼 여러 국가에서 널리 쓰이는 언어는 특정 국가가 아니라 언어권 클러스터로 시작합니다. 그다음 로컬 자료 → 글로벌 대표 사례 → 로컬 전이 가능성 순서로 확인합니다. 언어는 검색 순서를 정할 뿐 법적 관할권이나 실제 타깃 시장을 확정하지 않습니다.

넓은 시장·사업성 질문에서는 `industry-depth-backstop-02`이 조건부로 작동합니다. 제품과 대체재만 보고 결론내리지 않고, 그 판단을 뒤집을 수 있는 시장 경계/산업 구조, 규모·성장, 가격대, 기업용·인프라 대안, 보안·규제·기술 변화, 국내외 차이를 확인합니다. 단순 가격·기능 질문에는 이 깊이를 강제하지 않습니다.

## 실행 조건과 한계

웹 조사를 하려면 사용하는 AI에 검색과 원문 접근 도구가 있어야 합니다. AI 이용료와 사용량은 해당 서비스 기준을 따릅니다. FieldPilot에 유료 데이터나 API 계정이 포함되지는 않습니다.

보조 도구에는 Python 3.10 이상 구문 지원이 필요합니다. 먼저 `--help`로 입력 형식을 확인하세요. HTML 보고서는 `tools/render_report.py`의 `--no-pdf`로 생성할 수 있습니다. PDF는 별도 로컬 브라우저 환경과 실제 파일 확인이 필요하며, 공개본은 브라우저 sandbox를 끄지 않습니다.

AI 답변은 모델과 자료에 따라 달라집니다. 실제 고객 결제나 사용 기록 없이 수요, 매출 또는 성공을 보장하지 않습니다. 일반 AI보다 항상 더 정확하거나 사용량이 적다는 비교 결론도 없습니다.
